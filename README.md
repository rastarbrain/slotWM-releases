# slotWM releases

Signed and notarized downloads of [slotWM](https://rastarbrain.com/slotwm/), a
macOS window manager, and the update feed (`appcast.xml`)
slotWM checks once a day.

Download the latest version from
[Releases](https://github.com/rastarbrain/slotWM-releases/releases/latest), or
install it with Homebrew:

```sh
brew tap rastarbrain/tap
brew trust --tap rastarbrain/tap
brew install --cask rastarbrain/tap/slotwm
```

slotWM runs on macOS 15 or later, on Apple silicon and Intel Macs.

slotWM is free to try for 14 days, then $4.99 once for every future version.
The source code is not published here. Questions:
